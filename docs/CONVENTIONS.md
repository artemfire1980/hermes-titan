# HERMES-TITAN — Aider Conventions

> Canonical: `docs/CODE_EDITING_RULES.md` (методы правки).
> Этот файл — тонкий адаптер для Aider: стиль кода и ограничения.
> Подключается автоматически через `--read` в `aider_runner.py`.

## Область работы
Работай **только** в текущем workdir (`~/ai-system/projects/...`).
Не трогай `~/ai-system/scripts`, `~/ai-system/docs`, конфиги Hermes.

## Стиль Python
- Python 3.12, PEP 8, type hints обязательны.
- stdlib предпочтительнее сторонних зависимостей.
- Имена модулей — `snake_case` (дефис ломает import, DEC-034).
- `set -euo pipefail` в начале каждого bash-скрипта.
- Комментарии — на русском, кратко.

## Workflow
- Сначала тест, потом правка.
- Перед коммитом: `pytest` + `ruff` должны проходить.
- Один коммит = одна логическая правка.
- Сообщение коммита — по-русски или в стиле CHANGELOG.

## Запрещено
- Секреты читать/печатать. `.env` не коммитить.
- Ставить пакеты в venv Hermes вручную (DEC-012).
- Добавлять зависимости без явного запроса.
- Изменять файлы вне текущего workdir.
